# 看板页面视觉优化方案

> 状态：待确认 ｜ 产出日期：2026-10-28 ｜ 依据：`docs/design-preview.html`（效果预览）
> 参考规范：ui-ux-pro-max（Data-Dense Dashboard / Flat 风格 / 图标一致性规则）、Lucide 图标体系

---

## 1. 现状诊断

截图见 `assets/before-board.png`，逐项问题与证据：

| # | 问题 | 证据 | 影响 |
|---|---|---|---|
| 1 | **图标过小** | 侧栏/顶栏 14px、列头按钮 12px、卡片 meta 10–11px | 在 1x 屏上笔画糊在一起，几乎不可辨认 |
| 2 | **笔画过细** | `stroke-width="1.6"` + `viewBox="0 0 20 20"`，缩到 14px 后实际 ≈1.1px | 与 600 字重的文字并排时显得发灰、廉价 |
| 3 | **几何不统一** | 手绘路径：圆角半径、端点处理、栅格对齐各不相同 | 视觉上"不是一套图标"，这是"不够现代"的主因 |
| 4 | **语义弱** | 看板/列表/分析三个图标都是"横线/柱状"，14px 下几乎一样 | 侧栏需要靠文字才能区分，扫读效率低 |
| 5 | **meta 对比度不足** | 卡片 meta 文字 `#94A3B8` 于白底 ≈ **2.5:1** | 低于 WCAG AA 4.5:1，弱光环境读不清 |
| 6 | **命中区偏小** | 列头 `+`/`⋯` 按钮 22–24px | 低于 28px 建议值，误触/漏点 |
| 7 | **层次扁平** | 卡片仅有 1px 边框、无阴影；列头与卡片同底色 | 列与卡片的从属关系要靠间距猜 |
| 8 | **圆角不统一** | 卡片 8px、列 10px、筛选胶囊 999px、按钮 6–8px 混用 | 细节不齐，整体不够"整" |

图标现状清单（`public/js/utils.js`）：`plus close trash check chevron calendar subtask warning refresh sparkle clock arrowUp arrowDown filter more inbox archive edit user mail`，统一 20 viewBox / stroke 1.6，实际使用尺寸 10–16px。

---

## 2. 设计目标

1. **一眼可辨**：图标在 14px 下仍能区分（几何简化 + 2px 笔画）。
2. **一套系统**：24 viewBox、stroke 2、round 端点，全部替换为 Lucide 几何。
3. **信息密度不降**：不增大卡片高度，只做"同尺寸下更清晰"。
4. **可访问**：meta 文字对比度 ≥ 4.5:1，按钮命中区 ≥ 28px，焦点环可见。
5. **零依赖、离线可用**：不引 CDN / 图标字体（CSP 为 `script-src 'self'`，且项目坚持零 npm 依赖）。

## 3. Design Tokens（建议直接落到 `:root`）

```css
:root {
  /* 表面与描边 */
  --bg:            #f7f8fa;
  --surface:       #ffffff;
  --surface-2:     #f2f4f7;   /* 列底色 */
  --border:        #e6e8ec;
  --border-strong: #d6dae1;

  /* 文字（对白底对比度 ≈17:1 / ≈7.7:1 / ≈3.3:1，第三档仅用于辅助信息） */
  --text-1: #111827;
  --text-2: #4b5563;   /* 原 #94a3b8，仅 2.6:1，本次必须替换 */
  --text-3: #8a91a0;

  /* 主色 */
  --accent:        #5b5bd6;
  --accent-hover:  #5050c9;
  --accent-soft:   #eef0ff;
  --accent-border: #cdd0f7;

  /* 圆角（三档，禁止再出现 6/7/9/20 混用） */
  --r-sm: 8px;    /* 控件、按钮、标签 */
  --r-md: 10px;   /* 卡片 */
  --r-lg: 12px;   /* 列、面板 */

  /* 阴影（极轻，只有两层） */
  --shadow-1: 0 1px 2px rgba(16,24,40,.04), 0 1px 3px rgba(16,24,40,.06);
  --shadow-2: 0 4px 12px rgba(16,24,40,.08), 0 2px 4px rgba(16,24,40,.04);

  /* 图标 */
  --icon-sm: 14px;  /* 行内 meta */
  --icon-md: 16px;  /* 导航、按钮 */
  --icon-lg: 18px;  /* 列头、空态 */
}
```

字体维持系统栈（`-apple-system / PingFang SC / Microsoft YaHei`）——本项目是内部工具，不引入 Google Fonts（离线可用性优先）。

## 5. 组件级改造

### 5.1 侧栏
- 导航行高 32 → 34px，图标 16px、与文字间距统一 10px
- 激活态：整行深色 → **浅靛蓝底 + 左侧 2px 竖条**（更符合现代 SaaS 侧栏）
- 计数徽标：纯数字灰字 → 胶囊（`--surface-2` 底）；激活时随主色

### 5.2 顶栏与筛选栏
- 分段控件（看板/列表/分析）：高度 30 → 32，内部选中项带 `--shadow-1`
- 「新建任务」按钮：32px 高、9px 圆角、主色底 + 6% 阴影，图标 15px
- 筛选控件：高 30 → 32、圆角 8、`focus-visible` 2px 主色环
- 「已隐藏完成 >7 天」胶囊：补 `archive` 图标 + 数字用胶囊徽标（当前是裸数字，弱）
- 「已同步 · 18 秒前」：保持右对齐、`--text-3`

### 5.3 看板列
- 列宽 258 → 268px，列背景 `--surface-2`、圆角 `--r-lg`、内边距 10px
- 列头高度 36 → 40px；列名 12.5/650；计数改为胶囊徽标
- WIP 超限：`2/3` 徽标 → 琥珀色描边胶囊（仅超限时染色）
- 列头按钮：22–24 → 26px 视觉 + 28px 命中区，hover 6% 灰底
- 列底部「添加任务」：纯文字 → 图标 + 文字，整行 hover 底色

### 5.4 任务卡片（重点）
```
┌─────────────────────────────────┐
│ PL5-23  ▤                      ◉ │  ← 键号徽标 + 类型图标 + 头像
│ 补充设计系统色彩规范             │  ← 12.8px / 560
│ [安全]                          │  ← 标签 chip
│ ⚑ 逾期 3 天   📅 11月8日    ☑ 0/3 │  ← meta 11px / #4B5563
└─────────────────────────────────┘
```
- 键号：纯灰 monospace → **浅灰底圆角徽标**（可扫读、有节奏）
- 标题：字重 500 → 560，行高 1.45
- meta：图标 13px、间距 10px、颜色 `#4B5563`；优先级由"小圆点"改成"旗标 + 文字"（当前圆点几乎看不见）
- 卡片：1px 边框 + `--shadow-1`；hover 变 `--accent-border` + 加深阴影（不位移，避免抖动）
- 拖拽态：`transform: rotate(1.5deg)` + `--shadow-2`，落点列加 2px 主色描边

### 5.5 空态与细节
- 空列：虚线框「暂无任务」→ 居中图标 + 一句引导
- 「已归档 N 条 · 列表查看」：改为带 `archive` 图标的提示条（已有，补图标与间距）
- 所有可点击元素 `cursor: pointer`；`:focus-visible` 统一 2px 主色环

## 6. 实施计划

### P0 · 图标体系（约 2–3 小时，收益最大）
1. 重写 `ICONS`（Lucide 几何）+ `icon(name, size, strokeWidth?)`
2. 三档尺寸替换调用点，列头按钮补命中区
3. 卡片 meta 语义重排（优先级 → flag）
- **验收**：14px 下 6 个导航图标互不混淆；无残留 20 viewBox 图标；截图对比

### P1 · 视觉 token 与组件（约 3–4 小时）
1. `:root` 落地 tokens，替换散落色值
2. 侧栏激活态、顶栏/筛选栏、列容器、卡片
- **验收**：同一屏信息量与改造前一致；对比度检查通过；1280/1440/1600 三档无横向溢出

### P2 · 动效与打磨（约 2 小时，可选）
1. 统一 120ms 过渡；拖拽幽灵态
2. `prefers-reduced-motion` 降级
3. 空态插画、密度切换（紧凑/舒适）

**回归面**：只动 `public/css/style.css`、`public/js/utils.js` 与少量模板字符串，不触碰接口/状态/拖拽逻辑；每阶段跑现有验证脚本（临时实例 + curl + 截图）。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 图标替换遗漏调用点 | `icon()` 签名不变；`grep "icon('"` 全量核对 |
| 尺寸变大挤压卡片高度 | meta 行固定 18px 行高，图标 13px，卡片 padding 收紧 1px 抵消 |
| 对比度改动影响整体质感 | 仅改 `--text-2/--text-3` 两档，先在一屏验证再全站 |
| 视觉回归无自动化 | 保留 `assets/before-board.png` 基线，改造后同分辨率截图逐屏比对 |
| 破坏零依赖 | 图标以字符串常量内联，不引 `lucide` npm 包与 CDN |
