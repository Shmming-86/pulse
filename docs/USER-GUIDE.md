# Pulse 看板 · 使用说明

> 面向团队所有成员的日常操作指南。部署完成后浏览器访问 `http://<服务器地址>:4173` 即可使用。

---

## 1. 界面总览

左侧为导航栏：**看板 / 列表 / 分析**（工作区）与 **团队 / 动态**（协作）。顶部为搜索、筛选、视图切换与「新建任务」按钮。左下角显示当前操作人，点击可直接编辑个人信息。

## 2. 看板视图（日常主战场)

- 默认四列流转：**待处理 → 进行中 → 评审中 → 已完成**，列可以自定义（见下）
- **拖拽卡片**跨列流转、列内上下拖动排序；拖拽失败会自动弹回原位
- 配置了 **WIP 上限** 的列，列头计数变红即超载，提示先收尾再领新任务
- 每列底部「+ 添加任务」快速创建，回车提交、Esc 取消
- 卡片信息：类型胶囊（图标 + 任务/需求/缺陷/优化）、任务键（PLS-12）、标题、标签、优先级、截止日期（临期橙色 / 逾期红色）、子项完成度、估点、负责人头像（26px，点击可切换执行人）

**默认查询条件：隐藏 7 天前完成的任务**

- 看板默认不展示**完成时间超过 7 天**的任务，避免已完成的老任务长期占满「已完成」列
- 筛选栏右侧的胶囊按钮显示当前隐去了多少条（如「已隐藏完成 >7 天 8」）；
  「已完成」列底部也会提示「已归档 N 条 · 列表查看」
- 点击该胶囊按钮可临时显示全部任务，再点一次恢复隐藏；选择会记在浏览器里，刷新后保持
- 这些任务**不会丢失**：**列表视图始终展示全部任务**，分析视图的统计口径也不受影响

**看板列管理**

- 看板最右侧「+ 添加列」可新增看板列：设置列名、配色、WIP 上限，新列立即出现在看板上
- 每列标题右侧的 **⚙ 按钮**打开列菜单：**编辑列**（改名/换配色/调整 WIP）、**左移/右移**（调整顺序）、**删除列**
- 删除列时名下任务会转移到你指定的列，任务历史同步改写；若删除的是「完成」列，转移目标列将自动接管「完成」语义
- 约束：最多 12 列、至少保留一列、至少保留一个「完成」列

## 3. 任务管理

**新建**：右上「新建任务」或快捷键 `N`，必填仅标题。描述框右上角「预览」可先看 Markdown 排版效果；
标签区最后一个虚线框「+ 自定义标签」输入文字回车即可新建标签（点已选标签可取消，最多 8 个）。

**详情抽屉**：点击任意卡片打开，包含：

- 属性即时保存：状态、负责人、优先级、类型、估点、截止日期、标签、描述
- **时间信息**：创建时间、开始时间（首次拖入「进行中」等开始列的时刻）、完成时间，
  以及由开始到完成算出的周期天数；**开始时间与完成时间可以点输入框直接修改**
  （补录历史、修正误操作都可以），留空表示未开始 / 未完成，修改会写入活动记录
- **描述支持 Markdown**：默认看到的是排版后的效果，点右上角「编辑」可改源码，点到别处即保存。
  常用写法：`**粗体**`、`*斜体*`、`` `代码` ``、`- 列表`、`- [ ] 待办`、`[链接](https://…)`、
  `### 小标题`、`> 引用`、`| 表头 | 说明 |`（下一行 `| --- | --- |`）、三反引号代码块
- **子项清单**：拆解执行步骤，头部自动显示完成进度
- 任务时间线：创建、状态变更、指派记录全部留痕
- 删除需二次确认

**负责人切换（四个入口）**：

1. 看板卡片右上角头像 → 弹出成员菜单（含各人在办数量）
2. 列表页「负责人」列内联下拉
3. 任务抽屉的负责人字段
4. 团队页「待指派任务」面板的「指派」按钮

**搜索与筛选**：`Ctrl/⌘ + K` 聚焦搜索（支持标题、编号、标签）；支持按负责人 / 优先级 / 类型组合筛选，「清除筛选」一键还原。

## 4. 团队（人员维护）

- **新增/编辑成员**：姓名（不可重名）、角色、邮箱、十色头像，弹窗内实时预览
- **移除成员**：名下有任务时可选「转交给指定成员」或「转为未指派」；全部转移动作写入动态
- 每张成员卡展示在办 / 进行中 / 已完成 / 逾期四项统计与工作量占比
- 系统至少保留一名成员；首次部署请先到团队页把「管理员」改成自己的信息

## 5. 列表视图

适合跨状态全局浏览与批量核对：表头点击排序，行内下拉直接改状态或负责人，点击行打开详情。

## 6. 分析视图（效能复盘）

顶部自动生成一句话洞察。各图含义：

| 图表 | 怎么看 |
|------|--------|
| KPI 卡片 | 进行中、本周完成（对比上周）、平均/中位周期、完成率、逾期、在制工作量（估点） |
| 累计流图 (CFD) | 各状态任务数随时间的堆积；「进行中」带持续变厚说明在制品在积压 |
| 吞吐量 | 每周新建 vs 完成柱状；长期新建 > 完成说明排入过多 |
| 周期时间趋势 | 从开工到完成的平均天数，下降即交付效率提升 |
| 优先级分布 | 紧急占比过高说明缺少规划缓冲 |
| 成员负载 | 按估点展示各人未完成任务量与进行中占比，一键发现忙闲不均 |
| 成员周度统计 | 最近 8 周按人统计：完成任务 / 新建任务 / 开始任务 / 完成点数，热力表看投入节奏；可切换指标，右侧有 8 周合计与平均周期 |
| 在制与风险 | WIP 超限预警 + 逾期任务清单 |

## 7. 动态

按天分组的团队操作时间线：创建、状态流转、指派、成员变更一览，点击条目可跳回对应任务。

## 8. 快捷键

| 按键 | 功能 |
|------|------|
| `N` | 新建任务 |
| `Ctrl/⌘ + K` | 聚焦搜索 |
| `Esc` | 关闭抽屉 / 弹窗 |

## 9. 常见问题

- **数据会丢吗？** 所有操作实时写入服务器 SQLite 数据库 `data/kanban.db`（事务保护），刷新/断线不丢；浏览器仅显示「离线」提示并自动重连
- **改了任务没保存？** 属性修改失焦即保存，保存失败会有红色提示并可重试
- **想清空演示数据？** 找管理员执行 `npm run reset`（详见部署手册第 9 节）
- **谁在操作？** 每条动态都记录操作人与时间；当前版本为单团队协作模型，无个人账号密码
